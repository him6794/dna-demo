# DNA / RNA 核酸組合模擬器

使用磷酸基、五碳糖與含氮鹼基，探索核苷酸的連接方式及鹼基配對。介面使用繁體中文，支援滑鼠、觸控與鍵盤，無須帳號或網路服務。

## 開始使用

直接以瀏覽器開啟 `index.html`，或使用 Node.js 22 以上版本啟動本機伺服器：

```sh
npm start
```

開啟 <http://127.0.0.1:4173>。應用程式不需要安裝套件或建置；`npm install` 僅供開發及瀏覽器測試。部署時將 `index.html`、`index.css`、`index.js`、`simulator-model.js` 放在同一個靜態網站目錄即可。

## 操作方式

- 點擊、輕觸組件庫或聚焦後按 Enter，將組件加入畫布；也能從組件庫拖放。
- 點選畫布上的一個組件，再點選另一個組件以連線。點擊空白處或按 Escape 取消選取。
- 拖動組件可移動整組相連的組件。刪除連線後，已分離的組件可獨立移動。
- 選取組件後，使用工具列旋轉、解除連線或刪除。點擊連線可刪除該連線。
- 右鍵點擊組件進入旋轉模式，再於畫布拖動以旋轉相連組件；Shift 可精細調整，Escape 結束旋轉模式。
- 聚焦畫布組件後，方向鍵移動 10 像素；按住 Shift 時移動 1 像素。`[` / `]` 旋轉 15 度，Delete 刪除組件。
- 使用復原／重做按鈕，或 Ctrl / Command + Z 與 Ctrl / Command + Shift + Z 復原／重做。
- DNA / RNA 範例提供可編輯的起點；清除全部也可以復原。

## 儲存與檔案

進度會保存在目前瀏覽器的 `localStorage`；重新整理頁面會恢復進度。清除網站資料、使用不同瀏覽器或網址時，不會共享此資料。瀏覽器若禁止儲存，仍可使用模擬器並匯出 JSON 備份。以 `file://` 直接開啟時，儲存行為依瀏覽器而異，建議使用本機伺服器。

使用「匯出」下載 JSON 專案，再使用「匯入」還原。匯入時會檢查資料格式、數量及連接規則；無效檔案不會覆蓋目前專案。請定期匯出重要作品。

每份專案最多 500 個組件、1,000 條連線；匯入檔案上限為 1 MiB。組件座標範圍為 0–10,000 像素，防止無效資料產生無法操作的畫布。

## 模型範圍

這是教學用的**簡化連接模型**，不模擬原子、3D 幾何、化學反應、鍵能或核酸的 5′ / 3′ 方向。

- 去氧核糖可連接 A、T、C、G；核糖可連接 A、U、C、G。
- 鹼基配對為 A–T、A–U、C–G；每個鹼基最多連接一個糖和一個配對鹼基。
- 每個糖最多連接一個鹼基、兩個磷酸基；每個磷酸基最多連接兩個糖。共價骨架不混用兩種糖。
- 糖與鹼基之間的糖苷鍵也是共價鍵。氫鍵線條僅表示配對，不表示實際氫鍵數量。
- 可表示 RNA 鏈內配對與 DNA / RNA 雜合配對；不進行完整分子穩定性或生物學有效性判定。

## 開發與驗證

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

`npm test` 使用 Node.js 內建測試執行器驗證模型規則、斷線與序列化。Playwright 測試以 Chromium 驗證拖動、鍵盤操作、復原／重做、匯入／匯出、儲存及窄螢幕操作。GitHub Actions 在 Linux 執行相同檢查。

程式分工：`simulator-model.js` 管理資料與連接規則；`index.js` 管理互動、歷史與儲存；`index.html` / `index.css` 提供介面。正式網站沒有第三方 JavaScript 執行階段依賴。
